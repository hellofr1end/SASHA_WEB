# ТЗ: Генератор монстров

## Общее описание

Разработать простое веб-приложение для управления отрядом монстров. Приложение позволяет создавать монстров, атаковать их и управлять списком через интерфейс.

---

## Этап 1: Базовая структура (Урок 1)

### Задача 1.1: Создать HTML-разметку

Создать страницу с минимальной структурой:

- Заголовок "Менеджер монстров"
- Кнопка "Создать монстра"
- Кнопка "Атаковать"
- Пустой контейнер для карточек монстров

### Задача 1.2: Реализовать базовый JavaScript

1. Создать пустой массив `monsters`
2. Реализовать функцию `renderMonsters()`, которая:
   - Находит контейнер по ID
   - Очищает его содержимое
   - Проходит по массиву `monsters` и для каждого элемента создает карточку
   - Добавляет карточки в контейнер

### Задача 1.3: Реализовать создание монстров

1. Навесить обработчик события на кнопку "Создать монстра"
2. При клике добавлять в массив объект:
   
```javascript
{
    name: 'Гоблин',
    hp: 10,
    attack: 3
}
```

4. Вызывать `renderMonsters()` после добавления

### Задача 1.4: Базовый CSS

Оформить карточки монстров:
- Рамка
- Отступы
- Фоновый цвет
- Цвет текста для имени

---

## Этап 2: Механика боя

### Задача 2.1: Реализовать атаку

1. Навесить обработчик на кнопку "Атаковать"
2. Проверить, есть ли монстры в массиве
3. Если монстров нет - вывести сообщение
4. Если есть - взять первого монстра (метод `shift`)
5. Уменьшить его HP на 5
6. Если HP > 0 - вернуть монстра в начало массива (метод `unshift`)
7. Если HP <= 0 - не возвращать (монстр умирает)
8. Вызвать `renderMonsters()`

### Задача 2.2: Отображение состояния

В карточке монстра отображать:
- Имя
- Текущее HP
- Силу атаки

---

## Этап 3: Улучшения

### Задача 3.1: Добавить случайность

При создании монстра добавить случайные характеристики:
- Имя: случайное из списка `['Гоблин', 'Орк', 'Скелет', 'Дракон', 'Тролль']`
- HP: случайное число от 5 до 25
- Атака: случайное число от 1 до 6

### Задача 3.2: Визуальные улучшения

Добавить CSS-классы для разных состояний:
- Красный цвет HP, если меньше 50%
- Разный фоновый цвет для разных типов монстров (опционально)
- Плавные переходы при появлении/исчезновении

### Задача 3.3: Дополнительные кнопки

1. Кнопка "Удалить всех" - очищает массив и перерисовывает
2. Кнопка "Воскресить" - восстанавливает HP всем монстрам до максимума (если массив не пуст)

### Задача 3.4: Информация о количестве

Добавить сверху страницы счетчик:
"Монстров в отряде: X"
Обновлять при каждом изменении массива

## Критерии готовности

- [ ] При нажатии "Создать монстра" появляется карточка
- [ ] При нажатии "Атаковать" у первого монстра уменьшается HP
- [ ] При HP <= 0 карточка исчезает
- [ ] Каждый монстр имеет случайные характеристики

- [ ] CSS оформлен аккуратно
